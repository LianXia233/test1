## 1. 项目背景与目标

- **源项目**：Padavan（rt-n56u）固件，MIPS 架构，配置与逻辑深度耦合 nvram / rc / httpd。
- **目标形态**：在 **ARM64 / ImmortalWrt** 平台（`mediatek/filogic`）上以现代 OpenWrt 技术栈（UCI / procd / ubus / LuCI / feed）重写核心功能。
- **目标板型**：
  - MT7981B（ImmortalWrt 官方支持）
  - MT7987A（需现有补丁序列，参照 LianXia233/test 仓库 H5000M 方案，eMMC + Debian 13 移植经验）
- **分层拆解**：
  - **M1/M2** `libnvram`：nvram 配置层复刻（API 兼容层）
  - **M3** `rc-ng`：服务编排层（procd 服务注册表 + ubus 事件）
  - **M4** `luci-app-padavan`：管理界面层（LuCI 模块）
  - **M5** 应用包迁移：USB / QoS / VPN / DDNS / 5G 等
  - 内核 BSP 为 P0 基座（ImmortalWrt 主线 + 板型 overlay）
